# SMG 旧协议 seed 1 与 3 数值失效

两项 train/test 虽均返回 0、六任务 checkpoint 顺序关闭，递归检查发现分割优化器 Adam 二阶矩含非有限值：seed 1 从 T1 开始，seed 3 从 T3 开始，之后的 checkpoint 均不满足全状态有限要求。训练中另有极大损失及回放强度越界。两项判为数值失效，不纳入有效对比或均值；JSON 中保留原始指标仅作诊断。

seed 1 原钟约 23.787 小时（含旧 500k attempt），seed 3 原钟约 23.564 小时；距原 30 小时截止约 6 小时，不足以保证从头重跑完成。保留日志和 checkpoint，不假称无损续跑。旧 seed 5 已报告训练失败；修复 v2 的 seed 2、4 已独立完成，不能跨版本混算五 seed。
