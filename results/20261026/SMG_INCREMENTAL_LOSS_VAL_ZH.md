# SMG 两站点增量训练损失诊断

从固定 seed2 第一任务 v2 checkpoint 分支，在第二站 train 上使用生成回放执行 20 epoch 双元训练，以第一、二站 validation 的前景 micro Dice 评估；不读取测试集。此分支不是采样器精确续跑，也不是完整六域 SMG。

CE 两站 Dice 分别 0.01282 / 0.01138，预测前景比例 0.0219% / 0.0504%；CE+软 Dice 为 0.07176 / 0.20912，预测前景 5.4963% / 3.1675%，验证标注比例 1.1148% / 0.8661%。CE+Dice 此次改善了这两个验证站点但前景预测偏多，两个值仍低；单一 seed 和 checkpoint 不证明稳健优越，不按分数挑测试结果。

单站监督 CE 可学习前景、增量阶段却接近塌缩，支持继续检查回放质量与双元更新；本结果不能单独区分两者因果。后续对照冻结相同训练和验证，将双元更新与联合更新比较，不使用 test。
