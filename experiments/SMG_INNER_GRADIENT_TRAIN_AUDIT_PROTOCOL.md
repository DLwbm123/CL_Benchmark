# 预注册协议摘要

固定单一 pilot 第五任务 checkpoint 和站6 train 顺序前24切片；不使用 validation/test。seed701生成五个旧站提示的 DDIM200 回放并仅留在内存，seed703抽取回放，seed702划分虚拟批；批量8。当前站和虚拟内更新分别用 5e-5 与 5e-4，同一内梯度、批次及参数对比 global-norm clip1 和无裁剪；输出范数、缩放、相对步长和 outer loss。三批从相同 checkpoint 出发，每批临时更新当前域BN一次后恢复，无优化器更新。出现非有限数即失败。时限1200秒，实际存储上限1GB，单GPU。无自动资格门槛，不据此宣称完整方法效果。结果为批次聚合，不公开患者、图像、权重或向量。
