# SMG CE+Dice 六域验证 pilot

预注册随机初始化 seed 11 的六域训练正常退出，六个顺序任务 checkpoint 中的模型及优化器均为有限值。最终 checkpoint 六站 validation 前景 micro Dice 为 0.01015、0、0.53942、0.28393、0.57518、0.61665；均值 0.33755，最小值 0。两站前景几乎塌缩，未达到预注册的每站至少 0.05 门槛，因此该候选不进入按通过门槛预设的独立种子方案。完整预测与参考前景率见配套 JSON。

这是一个 seed 的适配实现，包含 ResUNet、每切片 min-max、50k 生成器更新、200 步采样、回放截断、内梯度裁剪，以及增量 CE+软前景 Dice；不等同作者代码或论文实验，且不可与旧配置混合汇总。此结果只使用训练集和验证集，没有使用测试集选参。训练约 21.1 小时，新增存储约 3.2 GiB；保留全部结果及负证据。
