# S3R / TED 标签插值二值化：两域对照

对两种方法各取固定已完成首任务的 seed 1、2 checkpoint，恢复模型及优化器、TED 教师或 S3R 参数重要性，在第二站训练20 epoch；原掩码整数截断与先按0.5二值化、再最近邻缩放对照，末尾仅在站1/2 validation 做前景 micro Dice。两臂评估同用0.5标签作为主口径，也保留原标签口径；均不访问测试集。每方法四臂完成20 epoch、rc0，最终模型参数和优化器有限；八臂共约26.85分钟、目录96KiB。程序采用双GPU独立运行，不保证逐位配对，固定首域起点也不是完整独立训练。
