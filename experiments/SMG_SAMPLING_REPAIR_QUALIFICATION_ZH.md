# 回放采样逐步约束资格诊断

固定 v2 seed2 首任务生成器与分割器，使用站2训练集前24个非空掩码和相同初始噪声，比较 200 步 DDIM 最终截断与每一步截断估计干净图像；没有使用测试集。末尾截断及逐步截断的饱和率分别为 95.1790% 和 0.0223%；对空掩码反事实的平均绝对变化分别为 0.00128 和 0.03510。固定 teacher 与条件掩码的前景 micro Dice 两者均为 0，预测前景比例分别为 2.3595%、0.3428%，条件掩码前景为 2.4589%。

逐步约束减少饱和并增加此度量的掩码响应，但未达到预注册的 teacher 前景 Dice 大于 0.05 且优于原方案的资格条件，不进入既定两站训练对照。teacher 对合成域可能不可靠，零重叠不等同于真实保真度为零；单 checkpoint、24 个掩码的诊断也不等同于完整 SMG 验证。逐步截断是非作者原生适配，不能证明生成质量改善。
