# 第六域空与非空训练切片的梯度对齐描述

固定 pilot 第五任务模型，排除先前诊断的24张切片后，按预定随机种子从站6训练集分别无放回抽取32张空掩码和32张非空掩码，各分4批，每批8张。每组分别以本组掩码与五个旧站提示生成回放，计算当前数据和生成回放的分割损失梯度余弦。

空掩码组四批余弦为 −0.0305、0.0545、0.0724、0.1040，平均 **0.0501**；非空组为 0.7639、0.8930、0.9033、0.9352，平均 **0.8738**。两个组的当前图像、掩码、生成回放及生成随机流均不同；生成条件也随组别变化，因此这一差异是关联性描述，不能归因于空掩码本身。患者分组语义未经确认，切片和批次不能假定独立。单个固定上游模型也不足以证明整体遗忘原因或分割性能收益，不以这些值选择方案。

实验只访问训练数据，不更新模型，也未使用 validation 或 test。八批均完整且数值有限，退出码0，耗时约398秒，新增存储32 KiB，处于预注册1200秒和1 GB限制内。结果文件包含各批梯度范数与损失；数据、权重和梯度向量未公开。
