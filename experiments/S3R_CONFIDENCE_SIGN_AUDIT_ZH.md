# S3R 重要性置信度符号错误

对照作者公开的 `agents/regularization_CISR.py` 和项目 S3R v3 适配发现：作者先计算熵 `H = -sum(p log(p+eps))`，再使用 `exp(-H)`；项目 `confidence_mask` 使用 `exp(H)`。后续两者均对空间做 min-max 归一化，但符号反转导致高置信度和高不确定性区域的相对权重方向反转。

在无真实数据的双像素合成输入上，作者公式对高置信度像素赋更大权重，项目适配公式相反；本次独立修正的函数恢复了作者公式方向，并对空间常数图保留有限值保护。该发现意味着旧 S3R v3 的重要性估计**不忠实于作者公式**。既有运行和结果应保留为该旧实现的测量，不能当作已验证的作者忠实复现；不能据此断言修复后的实际性能，也不能保证错误是唯一或主要原因。

本文件仅报告静态代码核查及合成测试；未用 test、未运行修复后的真实数据训练，也没有覆盖旧实现或旧结果。后续应在新协议中从头训练，或明确以固定旧首域模型重新计算旧域重要性建立诊断分支；所有对照仅通过 validation 决策，不能重用旧错误重要性冒充修复。作者代码与 README 关于形状先验训练存在歧义，私有权重不可用，故修正此公式仍不等于作者原生复现。
