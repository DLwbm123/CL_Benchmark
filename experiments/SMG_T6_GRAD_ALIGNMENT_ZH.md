# 第六域当前数据与生成回放梯度对齐诊断

固定 seed11 pilot 第五任务模型，在站6训练集顺序前24张切片上，以3个 batch 各8张、固定生成回放计算当前数据与回放数据的 CE+软前景 Dice 梯度。模型参数固定，每批临时使用当前数据更新 BN 后，分别计算两个梯度，最后恢复原参数与 BN；不执行优化，不使用 validation 或 test。

三个 batch 的梯度余弦依次为 **−0.304422、0.925085、0.851164**；对应当前梯度范数为 43.2371、14.7427、31.6904，回放梯度范数为 15.0180、17.6282、20.1310。第一个 batch 的两个方向相反，其余两个方向相近，说明这三个固定 batch 的方向并不一致。各 batch 的损失和回放站点提示数见配套结果 JSON。

本诊断使用一个固定上游模型、三个顺序 batch 和同一次生成回放，仅描述局部梯度；不能据此估计总体冲突频率，也不能证明遗忘原因或某项方法能改善分割性能。三个 batch 均完成且数值有限，退出码0；运行约108秒，新增存储32 KiB，低于预注册1200秒与1 GB上限。训练数据、权重和梯度向量未公开。
