# S3R 重要性估计 dropout 机制对照

使用两个固定首域项目模型，开始第二域前以**正确置信度符号**从零计算首域重要性，对照重要性估计时启用或禁用 MC dropout；随后两臂均按原配置启用训练 dropout，在第二域训练20 epoch，在站1/2 validation 评估。四臂均rc0，训练20 epoch，重要性、网络和优化器有限，先验在分割训练时保持冻结；约16.6分钟、68KiB，未访问test。独立GPU训练不保证位级配对。

按两种子、两站等权聚合，原标签口径的前景 micro Dice：重要性估计时 dropout **启用 0.26336，禁用 0.27980**，差 **+0.01644**。两个seed均值差为正、站均下降均未超过0.02，但平均改善未达到预注册的 +0.03 门槛，不能由此进入该协议规定的独立上游验证。

作者所公开源码在 eval 状态只给 dropout 设置 `is_training` 属性；所用PyTorch合成检查确认该属性不切换 dropout 的 `.training`。作者实际运行的环境和意图仍未知，不能声称其训练必然禁用 dropout 或据此定性作者方法。两臂采用正确置信度符号，旧错误符号不得恢复；二域、两个固定上游模型不足以断言该差异普遍有效或无效，不能证明根因或完整复现。只发布跨seed、跨站聚合；患者数据、图像、权重、标识和控制信息未公开。
