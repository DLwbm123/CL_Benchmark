# S3R 与 TED 验证集前景审计

冻结并只读评估各方法 5 个已有 v3 最终任务 checkpoint，在 6 站 validation 集进行像素汇总前景 Dice，记录预测和真实前景像素比例。未训练、未访问 test、未选择 seed 或 checkpoint。使用已有项目预处理和适配 ResUNet，所有 10 个 checkpoint 严格加载；60 个组合均完成，进程返回 0，数值有限。不同患者/站点的切片占比不同，micro Dice 不是患者平均 Dice，不可直接与原论文分数相减。

各站前景 micro Dice 为五 seed 均值：S3R 0.45579 / 0.55021 / 0.11171 / 0.02821 / 0.20628 / 0.41045；TED 0.23858 / 0.08253 / 0.00372 / 0.00057 / 0.05997 / 0.09309。对应预测前景比例均值分别为 S3R 1.9288% / 0.9566% / 0.6401% / 0.1863% / 0.4016% / 0.8612%，TED 0.4655% / 0.0670% / 0.0177% / 0.0055% / 0.0471% / 0.0732%；标注比例 1.1148% / 0.8661% / 5.3197% / 1.7750% / 1.1575% / 1.3249%。TED 多站预测前景接近零，S3R 个别站点亦表现很弱；这些结果不证明原论文方法无效，也不能确定原因。

总原钟约 146 秒，目录约 16 KB，预算 1200 秒及 1 GB。结果为项目适配版本验证审计，未证明作者原生代码表现或临床表现。数据、图像、权重和患者信息未发布；复现脚本要求自行提供数据、环境及模型权重，运行前设置 RUN_ROOT、WORK_ROOT、CL_DATA_ROOT。站点编号为本项目顺序，不能直接与论文的域字母对照。后续需要对齐来源顺序、预处理、评估、训练和网络实现，以验证集而非测试集决定是否修复或纳入。
