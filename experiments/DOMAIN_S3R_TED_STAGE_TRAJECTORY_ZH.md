# 第一站验证前景随训练阶段的轨迹

对两种项目适配方法全部五个 seed 的六个固定任务完成 checkpoint，逐个在项目第一站 validation 上计算前景 micro Dice 和预测前景率。该审计用于描述遗忘，不选择 checkpoint；无训练、不访问 test。全部60项完成且finite，进程rc0，152秒，独立原钟600秒、目录守卫1GB。

各阶段跨seed的前景micro Dice均值：S3R 0.78073 / 0.37712 / 0.26370 / 0.18828 / 0.24954 / 0.45579；TED 0.75376 / 0.60975 / 0.47072 / 0.17269 / 0.28350 / 0.23858。S3R 在第二阶段后下降明显，TED 在第四阶段后下降明显；两者后续有回升，不能将下降都归因于最后一次增量。均值不能揭示全部 seed 稳定性，完整分组结果见 JSON。这不是方法疗效对照，也不能据此认定造成遗忘的原因或声称作者原生实现失效。

评价使用项目HDF5 validation、现有 ResUNet 适配、切片像素micro汇总；与作者数据划分、站点顺序和病例级指标的差异仍需核实。公开材料不含数据、图像、权重及身份；脚本需自行提供数据、环境和checkpoint，并指定 RUN_ROOT、WORK_ROOT、CL_DATA_ROOT。
