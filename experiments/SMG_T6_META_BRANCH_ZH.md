# 第六域分割更新机制对照（validation）

固定同一个 seed11 六域 pilot 的第五任务模型、生成器和优化器，分支到站6训练；这不是完整六域训练，也不是精确恢复。seed11/13 分别比较 dual 与 joint，完整站6训练掩码、五旧域提示、DDIM200、clamp 回放、CE+soft Dice，20 epoch 后只评估站1、2、6 validation；不使用 test。各臂独立生成回放，不保证逐 batch 或逐位一致。

|---|---|---:|---:|---:|

双seed站1/2均值 dual 0.02670，joint 0.31476，差 +0.28807；站6均值分别 0.35150/0.63347。四臂返回码均为0，20 epoch，模型及优化器均有限；符合预注册旧站均值提升至少0.05、各站均值下降不超过0.02的资格门槛。原钟约3.43小时，目录72 KiB。预测与参考前景率及饱和率见聚合结果。

该门槛仅允许进一步机制研究，不自动以 joint 替换 SMG。两种更新也改变 BatchNorm 统计，不能把差异单独归因于元梯度；两个种子共享一个第五任务起点，因此不代表独立完整运行的稳健性，也不能证明合成回放保真或已解决六域遗忘。
