# 第六域回放缩放机制对照

固定同一 seed11 pilot 的第五域结束模型、生成器和优化器作为分支，在站6训练数据和五个旧域提示上比较直接 clamp 与逐切片 min-max 后 clamp，seed11/13 各训练20 epoch，只在末次评估站1、2、6 validation。四臂均正常退出、模型与优化器有限。

两个 seed 的站1/2 平均前景 micro Dice：clamp 0.00716，min-max 0.02797，差 0.02081，未达到预注册至少 +0.05 的门槛。站6跨 seed 均值分别 0.49522、0.56340。各臂完整站点分数、预测/真实前景率及饱和率见 JSON；min-max 显著降低边界饱和，但旧站前景 Dice 仍很低。

这不是完整 SMG 训练，也不是两次独立的六域初始化；两臂独立生成回放，不保证逐位配对，不能证明因果或样本保真。结果未通过预注册候选门槛，不据此推进该缩放方法。未使用 test；没有改动原 checkpoint 或旧实验。
